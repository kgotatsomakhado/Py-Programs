# Cashier Service Program

A simple Python console program that works as a basic cashier system.

The program allows the user to select a product, enter the amount paid by the customer, and calculate the change.

## Products

| Product | Price |
|---|---:|
| Burger & Chips | R49.66 |
| Pizza | R99.99 |
| Burger | R32.99 |
| Chips | R27.50 |
| Cool Drink | R10.00 |
| Ice Cream | R5.00 |

## Features

- Product selection
- Customer payment input
- Change calculation
- Basic input validation
- Option to serve another customer

## Requirements

- Python 3

## How to Run

Run the program using:

```bash
python main.py
```

Replace `main.py` with the name of the Python file if it is different.
